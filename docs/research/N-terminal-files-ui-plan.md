## 文件管理（F）

| 步 | 内容 | 验收 |
|---|---|---|
| F1 正确和诚实 | 冲突策略（覆盖、跳过、重命名、按大小和时间比较，“应用到全部”，默认不静默覆盖）；取消发 Abort、两端 1 s 内释放、清理 `.part`；接收目录里的符号链接不穿透；非 UTF-8 和带冒号的名字不让整个任务失败，按目标系统检查名字；每个失败给原因和办法，Abort 原因不截断 | 每种冲突策略、取消、符号链接、坏名字都有测试；错误文案对照表 |
| F2 大目录 | 流式清单（不再一次 4096 个上限）、.gitignore 和排除模式、符号链接和空目录明确处理 | 1 万个以上文件、node_modules 级目录传完 |
| F3 吞吐 | 块 ≥ 256 KB、复用文件句柄、阻塞 IO 放专用线程、前缀哈希分段 | 局域网回环 ≥ 500 MB/s 量级；续传前准备 ≤ 3 s；基准进 CI |
| F4 让路视频 | 应用层限速：文件速率 = 链路估计 − 视频 − 输入，留下限 | 大文件上传时视频冻结 ≤ 1 s、输入延迟 p95 比空闲高不过 20%，进 e2e |
| F5 断网续传 | 断线后自动重连续传；并行 2–3 条流 | 2 GB 中断 30 s 后自动续传，重发 ≤ 缺的部分 + 1 块 |
| F6 权限 | 只读模式、目录白名单、被控端可见的传输记录和进行中提示；MCP 和手机默认只读 | 权限组合的测试；被控端界面截图 |
| F7 远端操作 | 删除（进回收站）、重命名、移动、新建 | 测试；撤销或回收站可找回 |
| 以后 | zstd 压缩、预览、打开远端文件改完存回、手机端（SAF、分享菜单）、从远程窗口拖到本机 | |

| 步 | 内容 | 验收 |
|---|---|---|
| T1 被控端 | 常驻 PTY（Unix portable-pty、Windows ConPTY），多会话，scrollback 在被控端，重连回放（先屏幕快照再增量）；新流类型和能力位；权限开关默认关、撤销立即断开；以登录用户身份运行（Windows 服务用用户令牌，没人登录就拒绝并说原因，绝不给 SYSTEM shell）；审计日志 | 断网 30 s 恢复后 2 s 内可操作、scrollback 不丢；Agent 输出 100 MB 不卡；三个系统的实机测试 |

## 产品负责人定的（11-28）

- **观看模式以后加**：只看画面、不能操作（同行都有）；和终端的“只读观看”一起设计，Agent 用户常常只想看进度，手机上误触也不会出事。
- **不做帧率设置**：我们的帧率跟着内容走（变了马上编、马上发，最高到编码器上限），用户不用选；少一个选项，界面也少一个会被误解的地方。
