# 调研：国外远程桌面的界面细节（2026-11-28，Sonnet 子代理；只作设计参考）

可信度：很多官方页面 403/404 或没写这些状态。**已证实** = 有原文或亲眼看过截图；**建议** = 综合业内通行做法给的规格，不是哪家的原样；
**未核实** = 没查到。Jump Desktop、AnyDesk、TeamViewer、Splashtop、iTerm2 的界面整体未核实。截图只放在会话的临时目录做内部参考，不进仓库。

## 1. 设备列表、首页

- 已证实（Windows App，https://learn.microsoft.com/en-us/windows-app/get-started-connect-devices-desktops-apps）：
  左侧窄导航（收藏、设备、应用；底部设置、反馈）；标题右上搜索和刷新；过滤胶囊；列表和卡片两种视图；
  卡片上有类型、名字、配置、绿色对勾加“Ready”、“上次连接 16 小时前”、实心蓝色“连接”加“…”菜单。Android 版：整宽卡片、可折叠分组、底部三个标签。
- 建议：
  - 每行：状态点（绿在线、灰离线、黄要处理）、设备名、系统和“在线 · 延迟约 24 ms”或“离线 · 2 小时前在线”；
  - 只放一个主按钮（在线“连接”，离线“唤醒”或“查看原因”）；在线的排前面；
  - 首次空状态：一个大图标、“还没有设备”、一个主按钮“在这台电脑上安装被控端”、一行“已经装好？输入配对码”。

## 2. 连接中

- 已证实：Windows App 连接前有信任确认页（标题“连接前确认你信任这台电脑”，麦克风、摄像头、剪贴板开关，“不再询问”，整宽连接和取消）。
- 建议：
  - 0–300 ms 什么都不显示（防闪）；300 ms 起在原位置显示步骤（找到设备 → 建立加密连接 → 等第一帧）和已用秒数；
  - 取消一开始就在；超过 8 秒加一行“比平时慢，可能走了中继”；超过 20 秒走失败流程。

## 3. 连接失败、对方离线

- 建议：一句原因、一句下一步、最多两个按钮。
  - 例：标题“无法连接到 Mac mini”，正文“这台设备 2 小时前离线，可能关机、睡眠或断网”，按钮“重试”（主）、“查看设备状态”。
  - 分清三种：对方离线；对方拒绝或权限没开；本机网络问题。
  - 技术细节折叠在“详情”里，带可复制的错误码。

## 4. 网络变差、断线、重连

- 已证实：Parsec 的画面上有一个图标式浮层，网络或硬件有问题时旁边出警告图标和修复建议（搜索摘要，页面 403）。
- 建议：
  - 变差：画面上方不遮挡的黄色横幅“网络较差：丢包 8%，原因：本机到路由器（Wi-Fi）”加“查看建议”，不弹窗（和 CLAUDE.md 一致）；
  - 断线：保留最后一帧、压暗到 50%，顶部横幅“连接中断，正在重连…（第 2/5 次）”加取消，每次之间有倒计时；期间禁用输入并说明；
  - 恢复：横幅变绿“已恢复”，1.5 秒后消失，画面 200 ms 渐亮；5 次失败转到第 3 节的失败页。

## 5. 会话工具条

- 已证实：
  - Windows 远程桌面的连接栏默认在顶部居中、可左右拖，里面是平移、更多、键盘；“…”展开主页、断开、全屏、触控和鼠标切换
    （https://learn.microsoft.com/en-us/windows-server/remote/remote-desktop-services/clients/windows）；
  - Windows App 网页版工具条默认折叠；
  - Parsec：左上角一个图标；统计里帧率写“当前 / 跳帧”，码率“当前 / 最大”，软件解码时标“Software”（https://support.parsec.app/hc/en-us/articles/360001562772）。
- 建议：
  - 桌面：顶部居中的小胶囊，鼠标移到顶边才出现，3 秒后自动隐藏；内容固定：设备名、质量图标（三格信号）、全屏、键盘和快捷键、文件、断开（红色，放最右）；
  - 统计分两层：普通用户只看三格信号加一个词（流畅、一般、较差）；点开才看延迟、帧率、码率、丢包、直连或中继，数字用等宽字体；
  - 手机：可拖动贴边的半透明悬浮按钮，点开是底部抽屉；横屏放右侧。

## 6. 需要权限（macOS 屏幕录制、辅助功能）

- 建议：
  - 用步骤页、不用弹窗：“还差两个权限，才能被远程控制”；
  - 每项一行：图标、名字、一句用途、状态（已开、未开）、“打开系统设置”；有示意图标出系统设置里要勾哪项；
  - 页面自己轮询，勾上就变绿，不用点“我已开启”；提示 macOS 常要重启应用才生效，给“重启 PeerDesk”；
  - 没有权限时不假装能远程，状态点黄色（和 CLAUDE.md“没有权限就不提供远程”一致）。

## 7. 文件传输

- 建议：
  - 每个文件一行（名字、进度条、已传/总大小），顶部总进度加速度和剩余时间（“12.4 MB/s，约 2 分钟”）；剩余时间前 5 秒不显示（防乱跳）；
  - 暂停、继续、取消在总进度行上，每行也能取消；
  - 冲突对话框照 Windows 11 的三项：替换、跳过、保留两者，显示两边的大小和修改时间，“对所有冲突这样处理”；
  - 完成一行提示“已传 12 个文件（340 MB）”加“打开文件夹”；失败列出哪个文件、什么原因，给“重试失败的”；
  - 拖拽时窗口出现虚线框和“松开以发送到 Mac mini”。

## 8. 终端

- 已证实：
  - Ghostty：搜索框黑字金黄底、当前匹配黑字桃色底；命令结束通知默认关，开了默认 5 秒以上才触发；响铃默认只提醒和改标题；光标可选块、竖线、下划线、空心块，默认闪烁（https://ghostty.org/docs/config/reference）；
  - Warp：默认 Warp Dark / Warp Light，深浅两套；顶部标签栏、当前标签蓝色下划线、命令块头上显示耗时（https://docs.warp.dev/terminal/appearance/themes）。
- 建议：
  - 配色：深色 Dracula 一类、浅色 Solarized Light 一类，跟随系统深浅；
  - 字体：自带等宽字体（JetBrains Mono，回退 Menlo、Consolas），13 pt，行高 1.2，内边距 8 px；
  - 光标块状闪烁，失焦变空心；标签栏 32 px，当前标签明显下划线；
  - 搜索框浮在右上，匹配黄色、当前匹配橙色；
  - 命令结束：后台标签上一个小圆点；耗时超过 10 秒的命令在窗口在后台时发通知；响铃只在标签上闪一下。

## 9. 字体和间距

- 已证实：Windows App 用系统字体、蓝色实心主按钮、细线图标、圆角卡片。
- 建议：
  - 界面字体用系统字体（Windows Segoe UI、macOS SF、Linux Noto Sans、Android Roboto），中文回退系统中文字体；只有终端和统计数字自带等宽字体；
  - 基础字号桌面 14 px、手机 16 sp；间距刻度 4/8/12/16/24/32；图标统一细线 1.5 px；
  - 强调色只用一种蓝，只用于主按钮和选中；绿黄红只表示状态，不拿来装饰；深浅色用同一套语义色，不写死颜色值。

## 10. 手机

- 已证实：
  - Termius iOS 的键盘栏：在系统键盘正上方，shift tab、?、/、|、esc、tab、ctrl、alt 加方向键，4 个一组可调序可自定义，有“隐藏键盘”；
    长按终端再拖等于方向键，拖得越远重复越快，双击是 Tab，捏合调字号，三指点击粘贴
    （https://docs.termius.com/terminal/mobile-terminal 、https://termius.com/blog/8-tips-for-using-ai-agents-on-mobile-in-termius）；
  - Windows 远程桌面：直接触摸和鼠标指针两种模式，指针模式单指点左键、双指点右键、双指拖滚动、捏合缩放。
- 建议：
  - 第一次进会话时一次性的半透明提示，展示 3 个手势；键盘栏照 Termius（Esc、Tab、Ctrl、Alt、方向键、隐藏键盘），跟着输入法上沿走，不做独立悬浮窗；
  - 引导最多 3 页，不进主流程，可跳过。
