# PeerDesk 服务端部署说明

这个包里是 `peerdesk-server`（静态链接，任何 x86-64 Linux 发行版都能跑）和安装脚本。
需要 systemd。完整指南见仓库里的 `docs/deploy-server.md`。

## 三步安装

```bash
tar xzf peerdesk-server-*-linux-x64.tar.gz
cd peerdesk-server-*-linux-x64
sudo ./install.sh
```

脚本会：创建系统用户 `peerdesk`，装二进制到 `/usr/local/bin`，配置写到 `/etc/peerdesk/server.toml`
（已有就保留），自动探测公网 IP 填进中继地址（探测不到用 `--public-ip <IP>`），启动服务并设为开机自启，
最后打印**服务器指纹**。再运行一次就是升级。

## 放行端口（UDP）

| 端口 | 用途 |
|---|---|
| UDP 4433 | 信令（登记、找到对方、协助打洞） |
| UDP 3478 | 中继（直连不通时转发） |

```bash
sudo ufw allow 4433/udp && sudo ufw allow 3478/udp                      # ufw
sudo firewall-cmd --permanent --add-port=4433/udp --add-port=3478/udp && sudo firewall-cmd --reload   # firewalld
```

云服务器还要在控制台的安全组里放行这两个 UDP 端口。

## 两台电脑怎么用

两台电脑的 PeerDesk 窗口里“服务器（用设备码连接）”都填：服务器地址 `<公网IP>:4433` 和服务器指纹（填一次就记住）。
被控端勾选“允许远程控制”后会显示 9 位**设备码**和密码；控制端输入设备码和密码就能连接。
出问题时，客户端点“打开日志文件夹”把 `peerdesk.log` 发出来；服务端看 `journalctl -u peerdesk-server`。

## 常用命令

```bash
systemctl status peerdesk-server          # 状态
journalctl -u peerdesk-server -f          # 日志
journalctl -u peerdesk-server | grep 指纹  # 再看一次服务器指纹
sudo systemctl restart peerdesk-server    # 改完配置后重启
```

不要删除 `/var/lib/peerdesk`：里面是服务器身份，删了指纹会变，所有客户端要重新填。
