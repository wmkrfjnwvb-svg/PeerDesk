PeerDesk 测试版（macOS，Apple 芯片和 Intel 通用）
================================================

这是测试用的构建，用来在你自己的两台机器之间试远程控制。
注意：被控端现在显示的是一个合成的“演示桌面”，还不是真实屏幕；
控制端发出的键盘鼠标会到达被控端并显示在“收到的输入”一栏，但还不会真正操作系统。

安装
  把 PeerDesk.app 拖到“应用程序”文件夹。

第一次打开（没有经过苹果公证，Gatekeeper 会拦）
  方法一：在“应用程序”里按住 Control 点 PeerDesk（或右键）-> “打开”，在弹窗里再点“打开”。
          较新的 macOS 上如果没有“打开”按钮：先双击一次，再到“系统设置 -> 隐私与安全性”
          最下面点“仍要打开”。
  方法二：在终端执行
          xattr -dr com.apple.quarantine /Applications/PeerDesk.app

权限（接入真实屏幕和输入之后需要；现在演示桌面不需要，提前授权也无妨）
  系统设置 -> 隐私与安全性 -> 屏幕录制（“屏幕与系统录音”）：打开 PeerDesk
  系统设置 -> 隐私与安全性 -> 辅助功能：打开 PeerDesk
  改完后退出并重新打开 PeerDesk。程序包已做了本机签名（ad-hoc），权限记在 PeerDesk.app 上。
  每个测试版本的签名都不同，换新版本后可能要在列表里删掉旧的 PeerDesk 再重新授权。

使用（同一局域网）
  1. 两台机器都打开 PeerDesk。系统询问是否允许接收网络连接时选“允许”。
  2. 被控机：勾选“允许远程控制”，记下“本机地址”中的一个地址和“密码”。
  3. 控制机：在“连接”里填地址和密码（可选：粘贴被控机的设备指纹核对身份），点“连接”。
  4. 画面窗口里按 F12 显示/隐藏统计；点“断开”或关闭窗口结束。
  只有一台机器时：勾选“允许远程控制”后点“连接本机（自测）”。

服务端
  peerdesk-server 是信令和中继服务端，只在两台机器不在同一网络时需要：
  ./peerdesk-server <配置文件>（第一次运行前同样执行 xattr -d com.apple.quarantine peerdesk-server）。
命令行
  /Applications/PeerDesk.app/Contents/MacOS/peerdesk help

数据目录：~/.config/peerdesk

PeerDesk test build (macOS, universal: Apple silicon and Intel)
==============================================================

A test build for trying remote control between your own machines.
Note: the host currently streams a synthetic "demo desktop", not the real screen.
Keyboard and mouse input reaches the host and is shown under "Input received",
but is not injected into the OS yet.

Install
  Drag PeerDesk.app into the Applications folder.

First launch (the build is not notarized, so Gatekeeper blocks it)
  Option 1: in Applications, Control-click (right-click) PeerDesk -> "Open", then "Open" again.
            On recent macOS without an "Open" button: double-click once, then go to
            System Settings -> Privacy & Security and click "Open Anyway" at the bottom.
  Option 2: in Terminal run
            xattr -dr com.apple.quarantine /Applications/PeerDesk.app

Permissions (needed once real capture and input land; harmless to grant now)
  System Settings -> Privacy & Security -> Screen Recording ("Screen & System Audio Recording"): enable PeerDesk
  System Settings -> Privacy & Security -> Accessibility: enable PeerDesk
  Quit and reopen PeerDesk afterwards. The bundle is ad-hoc signed, so the permissions attach
  to PeerDesk.app. Each test build has a new signature: after updating you may need to remove
  the old PeerDesk entry from those lists and grant again.

Usage (same LAN)
  1. Open PeerDesk on both machines. Allow incoming network connections when asked.
  2. On the host: tick "Allow remote control"; note an address and the password.
  3. On the controller: enter the address and the password (optionally the host's fingerprint)
     and click "Connect".
  4. Press F12 in the remote window to toggle stats; click "Disconnect" or close the window to end.
  With one machine: tick "Allow remote control", then click "Connect to this device (self-test)".

Server
  peerdesk-server is the signaling and relay server, only needed across networks:
  ./peerdesk-server <config> (run xattr -d com.apple.quarantine peerdesk-server first).
Command line
  /Applications/PeerDesk.app/Contents/MacOS/peerdesk help

Data folder: ~/.config/peerdesk
